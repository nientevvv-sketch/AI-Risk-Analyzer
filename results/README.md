# Results

This folder stores model evaluation outputs, comparison tables, charts, and experiment artifacts.

## Suggested contents

```text
results/
├── model_comparison.csv
├── confusion_matrix.png
├── roc_curve.png
├── calibration_curve.png
├── feature_importance.csv
├── README.md
└── experiments/
```

## Guidelines

- Save final metrics and summaries here after running evaluation scripts.
- Keep generated artifacts separate from source code and raw data.
- Include a clear naming scheme for each experiment or model run.
- Prefer reproducible files such as CSV, JSON, and PNG over ad hoc outputs.

## Notes

This folder is intended for generated results, not for code or datasets.
